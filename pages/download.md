# 文件下载

这里提供一些可下载的文件资源。

<DownloadList />

## 使用说明

1. 点击文件列表中的下载按钮即可开始下载
2. 如果下载失败，请检查网络连接或稍后重试
3. 大文件支持断点续传功能
4. 可以通过文件类型筛选来快速找到需要的文件

## API 使用方法

您也可以直接通过API下载文件：

```
GET /api/download?file=<文件路径>
```

**参数说明:**
- `file`: 相对于download目录的文件路径

**示例:**
```
/api/download?file=0605/worker.zip
```

**安全限制:**
- 不允许路径遍历（包含 `..`、`\` 或以 `/` 开头的路径）
- 只能下载download目录下的文件
- 支持常见文件类型的MIME类型识别

## 支持的文件类型

- 压缩文件: `.zip`
- 文档文件: `.pdf`, `.doc`, `.docx`, `.txt`, `.md`
- 表格文件: `.xls`, `.xlsx`
- 代码文件: `.js`, `.css`, `.html`, `.json`
- 图片文件: `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`
- 音视频文件: `.mp3`, `.mp4`

---

*如需添加新的下载文件，请将文件放置在项目根目录的 `download` 文件夹中。*
