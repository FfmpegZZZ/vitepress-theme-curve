### 系统
本次教程是基于 Debian/Ubuntu 等debian系的Linux系统，如果你是其他系统，操作方式大同小异，同样可以参考。

首先我们先确保你使用ssh连上了你的服务器，如果你不知道怎么使用SSH连接服务器，你可以看[SSH连接服务器](/posts/2025/0119#ssh-客户端本项目为可选)。我们需要先安装docker,命令行输入以下命令使用脚本安装docker。

### Docker
命令行输入以下命令使用脚本安装docker
``` bash
bash <(curl -sSL https://linuxmirrors.cn/docker.sh)
```

脚本选择的镜像地址可以根据服务器所在位置自由选择。
## Run

安装完docker之后，我需要先拉去dify这个项目

请注意，请先确定你安装了 git,并且你的服务器可以正常访问 Github。如果不能正常访问，请自行寻找 Github 的加速镜像。

``` bash
git clone https://github.com/langgenius/dify.git
```

正常 Clone Dify项目之后 运行以下命令行拉起 Docker
``` bash
cd dify && cd docker && cp .env.example .env && docker compose up -d
```
请确保你的80/443端口未占用，dify这个docker compose内置了一个nginx，这也是很多人诟病的一点，所以你如果以及有了相关服务或者不仅仅部署dify，还是推荐在docker-compose 中将nginx部分删去，自行反代dify的端口。

如果完成了以上步骤并且和我一样没有其他报错，这说明你已经顺利运行起来了，现在你已经可以访问服务器的IP 直接访问，就可以进入到dify的webui界面了。
