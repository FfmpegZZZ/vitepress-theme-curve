# 1.1 驾驶证的种类及有效期

## 重点知识点

**无证驾驶处罚：** 200-2000元罚款，可15天拘留  
**准驾不符 = 无证驾驶**  
**必须随身携带驾驶证**

## 驾驶证类型
**A类（大型车辆）：**  
A1-大型客车 | A2-重型牵引挂车 | A3-城市公交车

**B类（中大型货车）：**  
B1-中型客车 | B2-大型货车

**C类（小型车辆）：**  
C1-小型汽车 | C2-小型自动挡汽车 | C3-低速载货汽车  
C4-三轮汽车 | C5-残疾人专用 | C6-轻型牵引挂车

**摩托车类：**  
D-普通三轮摩托车 | E-普通二轮摩托车 | F-轻便摩托车

**特种车辆：**  
M-轮式专用机械车 | P-有轨电车 | N-无轨电车

## 准驾范围

| 驾照类型 | 准驾车型                                   | 包含的其他准驾车型                     |
| :------- | :----------------------------------------- | :------------------------------------- |
| **A1**   | 大型客车                                   | A3、B1、B2、C1、C2、C3、C4、M           |
| **A2**   | 重型牵引挂车                               | B1、B2、C1、C2、C3、C4、C6、M           |
| **A3**   | 城市公交车                                 | C1、C2、C3、C4                         |
| **B1**   | 中型客车                                   | C1、C2、C3、C4、M                      |
| **B2**   | 大型货车                                   | C1、C2、C3、C4、M                      |
| **C1**   | 小型汽车                                   | C2、C3、C4                             |
| **C2**   | 小型自动挡汽车                             |                                        |
| **C3**   | 低速载货汽车                               | C4                                     |
| **C4**   | 三轮汽车                                   |                                        |
| **C5**   | 残疾人专用小型自动挡载客汽车                 |                                        |
| **C6**   | 轻型牵引挂车                               |                                        |
| **D**    | 普通三轮摩托车                             | E、F                                   |
| **E**    | 普通二轮摩托车                             | F                                      |
| **F**    | 轻便摩托车                                 |                                        |

**记忆技巧：**

*   高级别驾照通常包含低级别驾照的准驾车型。
*   A1 > A3, B1, B2
*   A2 > B1, B2, C6
*   B1 / B2 > C1, C2, C3, C4, M
*   C1 > C2, C3, C4
*   C3 > C4
*   D > E > F
*   其他类型（C2, C4, C5, C6, F, M, N, P）通常只对应其本身。

## 有效期管理
**初次申请：6年**  
**6年换10年条件：** 6年内每个记分周期未满12分  
**10年换长期条件：** 10年内每个记分周期未满12分  
**换证时间：** 有效期满90天内  
**换证地点：** 驾驶证核发地或驾驶证核发地以外的车辆管理所  
**过期不能开车**
